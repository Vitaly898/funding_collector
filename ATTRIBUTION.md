# Происхождение и разрешение

База репозитория — DN автора `yalishendaa`:

- source: https://github.com/yalishendaa/DN
- зафиксированный upstream SHA: `91af82be07c95c4aa092847eadf3bac68069883a`
- исходный README на этом SHA: https://github.com/yalishendaa/DN/blob/91af82be07c95c4aa092847eadf3bac68069883a/README.md
- пользователь сообщил о разрешении владельца использовать и fork DN. Это **сообщённое пользователем разрешение**, не независимо проверенный юридический документ и не общая публичная лицензия.

При локальной проверке полного tracked tree этого SHA не найден LICENSE/COPYING. Не приписываем DN MIT/Apache или иной лицензии и не расширяем reported permission на чужие сайты, branding, backend либо рыночные базы.

Добавленный пакет `funding_collector/` содержит новый public/paper путь и отдельный локальный private signer/worker с официальными signing SDK. Legacy compatibility остаётся явно отделённой. Исходные DN-файлы сохранены; корневой README описывает актуальные режимы и безопасные границы запуска. Эта заметка не устанавливает разрешение на перелицензирование. `origin` указывает на `Vitaly898/funding_collector`; репозиторий не объявляется GitHub-hosted fork, связь с upstream сохранена в Git history/remotes.

Реальные аккаунты, ключи, ордера, wallet approvals и production deployment в проверках не использовались. Локальные коммиты и публикация кода — отдельные действия по разрешению пользователя, не подтверждение live trading readiness.
