Ограничения исполнения

Size per order отдельно от Target size, лестница заявок, offset retry, автоматическое перевыставление, закрытие и циклы пока не поддерживаются live Worker. Здесь одна фиксированная post-only лимитка; offset применяется один раз при расчёте. Цена округляется от crossing до разрешённого шага. Кнопка «Рассчитать цены» обновляет публичный reference; сохранение цены не меняет действующие ордера.

Native HL и Entropy независимы. Только проверенные BTC/ETH/SOL для native и io:NVDA для Entropy при наличии совместимого Lighter Core/RH. Одинаковый base не означает одинаковый oracle / funding / settlement basis. Variational и EVEDEX не имеют private execution adapter.
